# FoodieLab Insights

푸디랩의 부동산·주식·AI·경제 데이터 인사이트와 공개 보고서를 모아 제공하는 GitHub Pages 저장소입니다.

비공개 분석 프로젝트의 원천 데이터, 내부 문서, 실행 코드와 검증 기록은 이 저장소에 복사하지 않습니다. 공개 검수를 마친 최종 HTML과 필요한 공개 자산만 보관합니다.

## 공개 사이트

- [FoodieLab Insights](https://foodie-repository.github.io/foodielab-insights/)

## 분류

- `reports/real-estate/`: 부동산 시장과 투자 판단 보고서
- `reports/stocks/`: 주식·기업·산업 보고서
- `reports/ai/`: AI·기술 보고서
- `reports/economy/`: 경제·정책 보고서

각 보고서는 발행 시점을 포함한 경로에 보존하고, 새로운 데이터로 판단이 달라지면 기존 글을 덮어쓰기보다 새 날짜의 보고서로 발행합니다.
